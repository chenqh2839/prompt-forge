# Prompt Forge

Prompt Forge 是一个本地优先的提示词优化桌面应用。它先识别原始提示中的信息缺口，通过 1–5 个可解释的问题进行多轮澄清，再生成包含角色、任务、背景、约束、输出格式与质量检查的专业提示词。

当前源码版本：`0.10.2`。

## 已实现

- Windows 优先、Tauri 2 跨平台应用
- React + TypeScript 单窗口工作台
- OpenAI 兼容 `/chat/completions` 请求层
- OpenAI、DeepSeek、Claude 兼容网关、本地 Ollama 配置
- 1–5 个澄清问题与“为什么问”解释
- 多轮追问，最多 5 轮；信息充分后自动生成
- 通用优化入口，以及学术写作、代码生成、文案创作三类内置场景
- 图像生成场景：视觉风格、构图、色彩、画幅与平台合规信息
- 可新增、编辑、删除的自定义场景模板，配置保存在本地 SQLite
- 本地项目上下文：项目目标、风格、角色、历史对话与素材
- 项目交互上下文：按项目选择历史生成记录，由模型生成可追溯摘要
- 角色复用：项目/手动背景已明确角色或技术栈时，避免重复角色声明，并单独显示一行判断理由；可在设置中关闭
- 上下文预算：显示 Token 估算，超限时明确截断并保留来源 ID
- 项目交互转模板：AI 提炼章节、变量和来源映射，确认后保存为自定义模板
- 变量提示词模板：有序章节、变量占位符、原始/填值双版本复制与 JSON 导入导出
- 日常对话回复助手：身份识别、背景追问、多语气回复与单条复制
- 主动发起沟通：从请假、约谈、问候等简单目的补全措辞
- 提示词与对话结果的前置背景注入
- 上下文附件：点击、拖拽或粘贴图片，支持图片缩略图与管理
- TXT、MD、PDF、DOCX 本地文本提取，随提示词一起发送给模型
- 附件随 SQLite 历史保存，按需恢复；不明确支持视觉的模型会阻止图片提交
- 可选择任务完成后保留或清空附件，偏好保存在本地
- 基于上一版结果和修改意见的多轮迭代
- 自定义背景色、文字色、强调色与 14–24px 基础字号
- 外观设置实时预览、恢复默认并通过 WebView `localStorage` 持久化
- SQLite 本地历史、删除、清空与 JSON 导出
- API Key 写入系统凭据库，不进入前端或 SQLite
- Windows NSIS 安装包配置
- Windows、macOS、Linux 构建检查矩阵

> 多轮分析与重新生成都会消耗所选服务的 Token。应用不提供任何 API Key；费用由用户与模型服务商结算。

## 快速开始

环境要求：Node.js 24+、pnpm 10+、Rust stable，以及各平台对应的 Tauri 系统依赖。

```powershell
pnpm install
pnpm desktop:dev
```

前端独立构建：

```powershell
pnpm build
```

构建 Windows NSIS 安装包：

```powershell
pnpm desktop:build
```

产物位于 `src-tauri/target/release/bundle/nsis/`。

Windows x64 发布压缩包建议命名为
`PromptForge-0.10.2-Windows-x64.zip`，包含：

- 双击安装的 NSIS 安装程序
- 便携版可执行文件
- `安装说明.txt`
- 内外部 SHA256 校验文件

安装包未进行商业代码签名，SmartScreen 可能提示“未知发布者”。

## 模型配置

启动应用后打开右上角“模型配置”：

1. 选择服务类型。
2. 填写 OpenAI 兼容的 Base URL，通常以 `/v1` 结尾。
3. 填写服务商提供的模型 ID。
4. 填写 API Key，并点击“保存配置”。
5. 点击“测试连接”验证配置。

也可填写完整 `/chat/completions` 地址。Ollama 默认地址为 `http://localhost:11434/v1`，本地服务通常不需要 API Key。
远程 Base URL 必须使用 `https://`；明文 `http://` 仅允许 `localhost`、`127.0.0.1` 或 `::1`，避免 API Key 在网络上明文传输。

API Key 使用系统凭据库保存：

- Windows Credential Manager
- macOS Keychain
- Linux Secret Service

模型 Base URL、模型名与推理参数保存在本地 SQLite 中。API Key 不写入 SQLite，也不会返回给 React 前端。

## 外观设置

打开右上角“模型配置”，切换到“外观设置”：

- 使用颜色选择器或直接输入 Hex 值修改背景、文字和强调色。
- 拖动滑块或输入数字调整 14–24px 的基础字号。
- 所有修改即时预览；“取消预览”恢复已保存设置。
- “保存外观”写入 WebView 本地存储，重启后自动恢复。
- “恢复默认外观”恢复项目内置的深色极客主题。

界面通过以下变量统一管理外观：

```css
:root {
  --bg-color: #080a0e;
  --text-color: #e8edf2;
  --accent-color: #70e1b6;
  --base-font-size: 14px;
}
```

## 项目与变量模板

左侧“项目上下文”选择或新建项目。项目上下文会自动附加到普通提示词分析、
重新生成和修改请求中，历史记录通过 `project_id` 关联项目，但删除项目不会
删除已有提示词。

选择项目后，主工作区会显示该项目的生成历史。勾选一组历史并点击“生成摘要”，
应用会调用模型提炼澄清约束、用户偏好、已确认决策和被否决方案。摘要按来源
记录集合与摘要版本缓存在 SQLite；来源记录更新后会自动重算。生成前会显示
来源 ID、摘要内容和 Token 预算，超出预算时明确列出被截断的记录。新历史保存
本次实际引用的来源 ID，可在结果区回看。

主工作区的“变量模板”是独立于场景模板的可复用提示词库：

1. 中性内置模板默认包含角色、任务、上下文、变量说明、规则、示例、输出格式和质量检查。
2. 用户可以增加、删除、重命名和调整章节顺序，也可以维护变量名称、说明和参考值。
3. “复制原始模板”保留 `{{变量}}` 占位符与填写说明，可粘贴到任意 AI 对话。
4. 填写变量后，“复制已填值提示词”会生成替换全部变量后的完整提示词。
5. 模板支持新建、编辑、删除、复制以及原生 JSON 文件导入/导出。
6. 模板编辑和复制仅在本机完成，不调用模型，不产生 Token 费用。

项目交互还可以点击“提炼为提示词模板”。应用会让模型从所选历史中识别稳定
章节、变量和规则，并展示“来源交互 → 章节或变量”的映射。提炼结果只打开为
可编辑草稿，必须由用户确认后才会保存到自定义模板库。

## 日常对话回复助手

顶部“日常回复”进入独立回复工作区：

1. 粘贴收到的消息。
2. 选择朋友、家人、同事、上级、客户、伴侣或其他身份。
3. AI 先提出 1–5 个背景问题，并解释每个问题为何影响回复。
4. 回答后 AI 判断是否继续追问，最多 5 轮。
5. 生成 3–4 条可直接发送的候选话术。
6. 每条可单独复制，也可以换一组重新生成。

如已选择项目，项目目标、风格、角色和前情会作为辅助背景发送给模型。

回复工作区还支持切换到“主动发起沟通”：只输入“写封请假邮件”之类的目的，
AI 会先补齐角色、沟通对象、任务背景、语气和输出格式，再生成多条可发送内容。

提示词输入区与回复输入区都提供“前置背景信息”，其内容会进入后续提问、生成
和修改请求。结果区下方的“继续对话 / 要求修改”可输入具体意见，或使用
“更正式、更亲切、更简短、更详细”等快捷动作持续迭代当前结果。

## 上下文附件

主提示词输入框上方提供“上下文附件”区域：

- 支持 PNG、JPG、JPEG、WEBP、TXT、MD、PDF 与 DOCX。
- 可点击“添加文件”、拖入附件，或直接粘贴剪贴板图片。
- 图片显示缩略图；文档显示图标、文件名、大小和截断状态。
- 每次最多 6 个文件、总计 20 MB；提取文本最多 60000 字符。
- PDF 使用 `pdfjs-dist` 在本地逐页提取，DOCX 使用 `mammoth` 提取正文。
- 图片通过 OpenAI 兼容的 `image_url` 发送；模型不支持或无法确认支持时会提示并阻止提交。
- 文档文本以 `[附件内容开始]` 与 `[附件内容结束]` 边界加入用户上下文。
- 文件不会经过额外第三方服务。内容随本地历史保存，恢复历史时按需加载。
- “完成后保留附件”默认开启并记住选择；关闭后生成成功时清空当前附件列表，但历史记录仍保留本次附件。

## 数据位置

v0.10.2 起支持在设置中自定义数据根目录。默认托管布局为：

```text
<data-root>/data/prompt-forge.sqlite3
<data-root>/webview/
<data-root>/meta/
```

首次升级时会迁移旧 SQLite、WAL/SHM 和 WebView 数据，逐文件校验后才会清理源文件。完整规则见 [DATA_LOCATION.md](docs/DATA_LOCATION.md)。

路径配置独立保存在系统配置目录的 `storage-location.json` 中，不随数据目录迁移。使用历史记录面板中的“导出”将全部记录保存为 JSON；“删除”和“清空”只影响本机数据。

## 隐私与数据

- API Key 应保存于 Windows 凭据管理器、macOS Keychain 或 Linux Secret Service。
- SQLite 数据库位于 `<data-root>/data/prompt-forge.sqlite3`。
- WebView 主题与本地配置位于 `<data-root>/webview`。
- 数据位置引导配置独立保存在系统应用配置目录的 `storage-location.json`，不随数据目录迁移。
- 卸载应用不会自动删除数据库、主题配置或系统凭据。
- 模型调用时，用户选择的内容会发送至用户配置的模型服务 endpoint；Token 费用由用户承担。
