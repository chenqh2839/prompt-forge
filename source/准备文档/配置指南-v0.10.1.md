# Prompt Forge v0.10.1 配置指南

## 1. 安装与启动

### 安装版

1. 解压 `PromptForge-0.10.1-Windows-x64.zip`。
2. 打开“安装版”目录。
3. 双击 `Prompt Forge_0.10.1_x64-setup.exe`。
4. 按向导完成当前用户安装。
5. 通过桌面“Prompt Forge”快捷方式启动。

### 便携版

1. 打开压缩包中的“便携版”目录。
2. 保持 `Prompt Forge.exe` 与 `WebView2Loader.dll` 位于同一目录。
3. 双击 `Prompt Forge.exe`。

系统要求：Windows 10/11 x64，以及 Microsoft Edge WebView2 Runtime。

## 2. 模型服务配置

打开应用右上角“设置”，进入“模型连接”。

### OpenAI

- 服务：OpenAI
- Base URL：`https://api.openai.com/v1`
- 模型：填写账号可用的模型 ID，例如 `gpt-4.1-mini`
- API Key：填写 OpenAI API Key

### DeepSeek

- 服务：DeepSeek
- Base URL：`https://api.deepseek.com/v1`
- 模型：推荐 `deepseek-chat`
- API Key：填写 DeepSeek API Key

如果特定模型出现“JSON 不完整”，优先切换至 `deepseek-chat`，再检查输出预算和服务商状态。

### Claude 兼容网关

- 服务：Claude 兼容网关
- Base URL：填写网关提供的 OpenAI 兼容 `/v1` 地址
- 模型：填写网关中的 Claude 模型 ID
- API Key：填写网关要求的 Key

该模式要求网关支持 OpenAI `chat/completions` 协议，不直接连接 Claude 原生 Messages API。

### 本地 Ollama

- 服务：本地 Ollama
- Base URL：`http://localhost:11434/v1`
- 模型：本机已拉取的模型 ID
- API Key：通常留空

本地模型需要具备足够的上下文窗口和 JSON 遵循能力。

## 3. API Key 与隐私

- API Key 不会写入 SQLite、源码、日志或历史导出。
- Windows 使用系统凭据管理器保存 Key。
- 点击“删除已保存的 Key”可清除当前服务的凭据。
- 提示词、项目、附件、历史和模板默认保存在本机。
- 只有实际调用模型时，相关内容才会发送至用户配置的模型服务。

## 4. 项目固定上下文

在左侧“项目”中新建或编辑项目，可维护：

- 项目名称
- 项目目标
- 风格
- 角色
- 历史对话与已定决策
- 素材

这些字段在普通分析、重新生成、修改和变量实例请求中作为项目固定上下文发送。

## 5. 项目交互上下文

1. 在左侧选择项目。
2. 主工作区会列出该项目的历史生成记录。
3. 勾选需要参与本次任务的一条或多条记录。
4. 点击“生成摘要”。
5. 检查每条来源记录的约束、偏好、决策和被否决方案。
6. 根据任务规模调整“上下文预算”。
7. 若显示截断提示，提高预算或取消部分勾选。
8. 确认“本次将引用”清单后开始分析。

默认预算根据所选模型的保守上下文比例计算。预算输入框允许手动覆盖。

摘要只发送压缩后的结构化信息；不会把所有历史原文直接拼入新提示词。摘要会缓存在本地 SQLite，来源历史更新后自动失效。

## 6. 项目交互转模板

1. 在项目交互列表中勾选一条或多条历史。
2. 完成并确认最新摘要。
3. 点击“提炼为提示词模板”。
4. 检查“交互内容 → 模板章节映射”。
5. 在模板编辑器中修改章节名称、顺序、正文和变量定义。
6. 确认后点击“保存提示词模板”。

模板不会自动入库。保存后会进入自定义变量模板库，并保留来源记录 ID 和映射关系。

## 7. 变量模板

默认内置模板为中性“通用提示词模板”，包含：

1. 角色
2. 任务
3. 上下文
4. 变量说明
5. 规则
6. 示例
7. 输出格式
8. 质量检查

章节可增加、删除、重命名和调整顺序。“变量说明”章节必须保留，但可以改名和移动。

两种复制方式：

- “复制原始模板”：保留 `{{变量}}` 占位符和填写说明。
- “复制已填值提示词”：先填写变量，再复制替换完成的最终提示词。

模板可通过原生文件选择器导入或导出 JSON。

## 8. 附件配置

支持格式：

- 图片：PNG、JPG、JPEG、WEBP
- 文档：TXT、MD、PDF、DOCX

限制：

- 每次最多 6 个文件
- 总大小最多 20 MB
- 单个图片最多 6 MB
- PDF 最多 15 MB
- DOCX 最多 10 MB
- 提取文本总计最多 60000 字符

图片需要模型支持视觉输入。未知模型或不支持的模型会阻止图片提交，不会静默丢弃。

扫描版 PDF 没有文字层时需要先进行 OCR。

## 9. 数据位置与备份

SQLite 数据库：

```text
%APPDATA%\com.promptforge.desktop\prompt-forge.sqlite3
```

建议通过“历史”区域的导出功能备份记录。卸载应用不会自动删除 SQLite 数据库或系统凭据。

## 10. Token 费用

以下操作会调用模型并产生费用：

- 开始分析和每轮澄清
- 最终提示词生成
- 重新生成
- 继续修改
- 项目历史摘要
- 项目交互转模板

模板编辑、原始/填值复制、导入导出和本地历史浏览不会调用模型。

建议在模型服务商控制台配置用量提醒和费用上限。
