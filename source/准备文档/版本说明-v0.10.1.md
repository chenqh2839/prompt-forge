# Prompt Forge v0.10.1 版本说明

发布日期：2026-10-25  
发布平台：Windows 10/11 x64

## 修复内容

- 为 Tauri 原生窗口配置深色初始背景，避免 WebView2 首帧使用默认白色表面。
- 在 `index.html` 中增加首屏关键样式和品牌启动层，使 CSS 与 React 加载前即保持深色。
- 主题初始化脚本在无历史配置时也主动应用默认深色主题。
- 持久化的浅色、深色或自定义主题会在 React 挂载前恢复。
- 同步更新浏览器 `theme-color` 和根元素背景，减少启动颜色跳变。

## 启动顺序

```text
原生窗口深色背景
  → HTML 品牌启动层
  → 本地主题变量注入
  → React 主界面首帧
```

该版本不改变数据、历史、项目、模板、附件或模型调用行为。

## 验证状态

- 前端生产构建通过。
- Tauri 配置校验与 Windows 发布构建通过。
- 安装版和便携版启动验证通过。
- 持久化主题在 React 挂载前恢复。
