# Prompt Forge v0.10.3 - Windows x64

本版本增加历史记录归档整理和可安全放弃的分析流程。

## 新增

- 历史记录支持单条移动和复选框多选批量移动。
- 项目选择器支持搜索、移动到现有项目以及移回“未归档”。
- 移动操作只更新 `history.project_id`，不删除记录、不生成副本。
- 批量移动使用单个 SQLite 事务；任一记录无效时全部回滚并返回失败明细。
- 提示词分析进行中可点击“放弃本轮分析”。
- 放弃会取消当前请求、丢弃本轮结果并恢复编辑态，同时保留原始提示词、背景和附件。

## 安全与兼容

- 历史表复用已有可空的 `project_id` 字段，无需破坏性数据库迁移。
- API Key 的 keyring service、模型 endpoint、数据目录迁移和导出逻辑未修改。
- 取消请求使用独立 request ID，重复取消或请求完成后取消不会报错。
